
📊 Meta Ad Performance Dashboard (Power BI)

🚀 Project Overview

This project presents an interactive Meta (Facebook & Instagram) Ads Performance Dashboard built using Power BI. It provides a comprehensive view of marketing performance by analyzing key metrics such as impressions, clicks, engagement, conversions, and budget utilization.

The dashboard is designed to help marketing teams, analysts, and decision-makers track campaign effectiveness, identify trends, and optimize ad strategies for better ROI.

🎯 Key Objectives

Monitor ad campaign performance in real time

Analyze user engagement behavior across demographics and platforms

Evaluate conversion efficiency and purchase trends

Track budget allocation and utilization

Enable data-driven decision-making for marketing optimization

📌 Key Metrics (KPIs)

Impressions: 71.6K

Clicks: 8,126

CTR (Click Through Rate): 11.35%

Engagement Rate: 13.13%

Conversion Rate: 5.44%
Purchase Rate: 0.62%
Total Engagement: 29.3K
Purchases: 442
Total Budget: $2.54M
Avg. Budget per Campaign: $50.72K

📊 Dashboard Features

1. Performance Overview

High-level KPI cards for quick insights
Color-coded metrics for better readability
Snapshot of campaign health and effectiveness

2. Audience Insights

Engagement by Gender (Donut Chart)
Engagement by Age Group (Histogram)
Helps identify high-performing audience segments

3. Geographic Analysis

Interactive map visualization
Tracks engagement distribution across global regions

4. Time-Based Analysis

Monthly and daily trends using calendar view
Weekly & hourly engagement trends
Helps identify peak engagement periods

5. Campaign Type Analysis

Performance comparison across:
Carousel Ads
Image Ads
Stories
Video Ads
Metrics include impressions, clicks, CTR, conversion rate, and purchase rate

6. Interactive Filters

Dynamic slicers for:
Campaign Name
Target Interest
Metrics selection
Enables customized data exploration

🛠️ Tools & Technologies

Power BI – Data visualization & dashboard design
DAX (Data Analysis Expressions) – KPI calculations & measures
Data Modeling – Relationships & transformations
SQL (optional backend) – Data extraction and validation

📈 Business Insights

High CTR (11.35%) indicates strong ad creatives and targeting
Engagement rate (13.13%) shows effective audience interaction
Lower purchase rate (0.62%) suggests scope for funnel optimization
Certain ad types (e.g., Stories/Carousel) outperform others in engagement
Peak engagement observed during specific hours and days
