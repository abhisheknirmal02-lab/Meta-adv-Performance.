## 🚀 Project Overview
This project presents an interactive Meta (Facebook & Instagram) Ads Performance Dashboard built using Power BI. It provides a comprehensive view of marketing performance by analyzing key metrics such as impressions, clicks, engagement, conversions, and budget utilization.

The dashboard enables marketing teams and analysts to make data-driven decisions and optimize campaign performance for better ROI.

---

## 🎯 Key Objectives
- Track campaign performance  
- Analyze audience engagement  
- Optimize conversion funnel  
- Monitor budget utilization  
- Enable interactive data exploration  

---

## 📌 Key Metrics (KPIs)
- **Impressions:** 71.6K  
- **Clicks:** 8,126  
- **CTR:** 11.35%  
- **Engagement Rate:** 13.13%  
- **Conversion Rate:** 5.44%  
- **Purchase Rate:** 0.62%  
- **Total Engagement:** 29.3K  
- **Purchases:** 442  
- **Total Budget:** $2.54M  
- **Avg Budget per Campaign:** $50.72K
